# Contributing to Geeklog Documentation

This repository is intended to hold the official English documentation for Geeklog. The migration is at an initial planning stage.

1. Fork this repository and create a topic branch for one documentation improvement.
2. Submit a pull request explaining the affected Geeklog version, source references and any links or anchors changed.
3. Verify examples against the relevant Geeklog release or source code; mark historical material clearly.
4. Do not remove legacy HTML paths or configuration anchors until compatibility checks pass.
5. Do not import material from old wiki captures without checking provenance and reuse permissions.

The final document layout, version policy, tooling and build checks will be established through reviewed contributions.

# Installing and upgrading Geeklog

This page is an **initial migration outline**, not yet a complete installation procedure.

The existing official installation instructions are in [Geeklog Core's install.html](https://github.com/Geeklog-Core/geeklog/blob/master/public_html/docs/english/install.html).

## Before installation

1. Choose the Geeklog release you intend to install.
2. Check the **PHP, database and extension requirements for that exact release** in the bundled instructions; older instructions can contain unsupported or insecure software versions.
3. Back up the site files and database before upgrading an existing installation.
4. Follow the release-specific installation or upgrade instructions included with the downloaded distribution.

# Geeklog configuration (compatibility prototype)

> **Incomplete pilot only.** Do not replace the complete configuration reference with this sample.

Geeklog's Configuration administration uses help links that may point to individual entries within the bundled `config.html`. Each such fragment identifier must remain stable in generated HTML.

## Site configuration

<a id="desc_site_url" name="desc_site_url"></a>

### site_url

Base URL of the website. See the [current bundled reference](https://github.com/Geeklog-Core/geeklog/blob/master/public_html/docs/english/config.html) for details. Verify the accepted value and behavior against the relevant Geeklog release.

<a id="desc_site_name" name="desc_site_name"></a>

### site_name

Website name. Consult the current bundled reference and the configuration code for the version installed.

This small sample demonstrates explicitly preserved legacy anchors. It does **not** document all configuration options.

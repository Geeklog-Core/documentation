# Administration — documentation preview

> **Work in progress.** This overview demonstrates a Markdown-based administration page; check Geeklog 2.2.2's bundled documentation for detailed instructions.

## Accessing administration

Sign in using an authorized administrator account. Available commands depend on your assigned rights.

## Configuration

Review settings in the Configuration section. Follow the context-sensitive help links, which target the historical `docs/english/config.html#desc_...` fragments in the embedded distribution.

## Plugins

Bundled plugins can provide separate configuration and help screens. Preserve their original documentation paths while migration is incomplete.

## Safe changes

Back up the database and relevant files before installation, upgrade, or major settings changes. Test unfamiliar changes in an isolated environment.
